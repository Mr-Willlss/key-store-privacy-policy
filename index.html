A simple flow

Copy. Keep. Reuse.

Clipboard capture is designed around Android’s rules and your choice to use Keystore.

1

Set up Keystore Keyboard

Enable it in Android settings and select it when you want to use Keystore’s keyboard and clipboard panel.

2

Copy text as usual

Keystore can save copied text while the app or keyboard can access Android’s clipboard. Capture is subject to Android restrictions.

3

Find it when you need it

Search or manage entries in the archive, or choose a saved clip from the keyboard to paste it.

Privacy is part of the design

Your clipboard belongs to you.

Keystore is built to keep saved clipboard content local and under your control.

Read the full privacy policy ↗

Android may restrict clipboard access even when Keystore is ready to capture. The app does not secretly poll the clipboard in the background.

1

Encrypted clipboard content

The saved content field is encrypted with AES-GCM using a key held by Android Keystore. Archive previews and metadata are also stored locally.

2

Optional cloud sync

Cloud sync is off by default. When enabled, eligible clipboard entries are sent over HTTPS to your account and protected by row-level access rules and database encryption at rest. This is not end-to-end encryption.

3

Sensitive fields are treated carefully

The keyboard suppresses clipboard and learning features in recognized sensitive input fields, and Android-marked sensitive clips are excluded.

4

Network use

Internet access supports an optional English dictionary download and, only when opted in, account-based clipboard sync. Dictionary requests do not include clipboard contents.

i

How many clipboard entries can Keystore keep?

The app does not set a fixed maximum number of saved entries. In practice, available space on the device is the limit. Copying identical text updates its existing entry instead of making a duplicate. Android may also prevent some copies from being captured.

Building Keystore across devices.

Keystore is adding an optional account-based cloud archive while keeping the on-device archive. This snapshot separates coded work from what still needs configuration or device verification.

Implemented

Android app and keyboard

Keystore has a companion app, custom keyboard, encrypted local clipboard archive, search, favorites, rich-text editing, trash, and clipboard insertion from the keyboard.

Cloud foundation

Supabase archive and account rules

The Supabase project and owner-scoped clipboard table are live. The web archive is published at Keystore Web Archive. Google OAuth credentials and Android sync still need setup and verification.

Connect and verify

Updated 26 November 2026. The source build and physical-device behavior remain unverified for the cloud work.

Done / implemented

  • Built the Android companion app and custom Keystore Keyboard.
  • Added a local Room database and clipboard archive with search, editing, favorites, trash, and keyboard insertion.
  • Added duplicate detection: copying identical text updates the existing clipboard entry and copy count.
  • Encrypted saved clipboard content with AES-GCM using a key held by Android Keystore. Archive previews and metadata are also stored in the local database.
  • Added local keyboard suggestions, settings, themes, and resizing.
  • Added a passphrase-based backup encryption codec; complete in-app backup export and restore are still listed as unfinished.
  • Created this responsive product website and linked the supplied privacy policy.
  • Created the Supabase Keystore Cloud project and owner-scoped clipboard table with row-level security. Authenticated clients have only select, insert, update, and delete privileges.
  • Added Room sync identifiers and pending-change state, a Google identity token exchange path, encrypted local session storage, network-constrained sync jobs, and an opt-in sync panel.
  • Added a responsive web archive with a Google sign-in entry point, search, editing, favorites, trash/restore, copy, TXT, and print/PDF actions.
  • Published the Keystore home page, web archive entry point, and cloud-sync privacy policy at the public GitHub Pages site.
  • Added Android TXT, PDF, and DOCX export; DOCX can be opened in Google Docs.

Checked: app/build.gradle.kts, AndroidManifest.xml, MainActivity.kt, ClipboardRepository.kt, AppDatabase.kt, ContentCipher.kt, BackupCodec.kt, README.md, KEYSTORE_CHANGES.md, KEYSTORE_AUDIT.md, PLAY_STORE_RELEASE_CHECKLIST.md, and PRIVACY_POLICY.md.
