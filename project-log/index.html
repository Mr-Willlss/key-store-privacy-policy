Keystore implementation log

Goals

  • Keep the local clipboard archive available offline and synchronize eligible items to Supabase when signed in, opted in, and online.
  • Let users access their synced archive on Android and the web from any device.
  • Edit copied text, preserve supported formatting, and export TXT, PDF, and DOCX.
  • Improve keyboard comfort and accuracy; document progress and remaining work.

Decisions

  • Room remains the on-device archive. Clipboard text is encrypted with Android Keystore AES-GCM before it is saved locally.
  • Cloud sync is off by default, requires Google sign-in and explicit opt-in, and uses network-constrained background retries.
  • Cloud content is sent over HTTPS, restricted by account-scoped Supabase Row Level Security, and encrypted at rest by the provider. It is not end-to-end encrypted.
  • Entries marked sensitive are excluded from sync. Local records retain the account owner so pending changes are not sent to a different account on a shared device.
  • The web client uses the Supabase publishable key and signed-in user JWT. No service-role key is shipped to clients.
